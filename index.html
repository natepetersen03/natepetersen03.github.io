Group Assignment Project: LeetCode Redesign

For our project, we redesigned LeetCode with five additional new features: Learning Pathways, Real World Problems, Debugger Tool, brainstorm Mode, and AI Chatbot Assistance.

  • Learning Pathways (Course View): Introduced a hierarchical tree view to guide learners through concept progression, reducing confusion about where to start and reinforcing foundational knowledge.
  • Real World Problems: Added a description of how each problem applies to real-world software engineering scenarios, fostering greater user understanding.
  • Debugger Tool: Enabled in-app debugging with breakpoints and variable inspection, streamlining the code-testing workflow without external editors.
  • Brainstorm Mode: Facilitated real-time collaborative coding sessions, mirroring pair-programming best practices to strengthen peer learning and communication skills.
  • AI Chatbot Assistance: Designed reflective, scaffolded prompts to guide users through problem-solving steps without revealing solutions, promoting metacognition.

Final Project: Sorting Visualizer User Testing

I conducted user tests with 3 participants, all engineering majors at Georgia Tech. In each test, users performed core tasks relating to learning about BSTs, Insertion Sort, and Merge Sort.

After completing the initial prototype and conducting user tests, I gathered feedback that was incorporated for the final prototype. Below are the three main insights integrated into the final prototype:

  • Progress Indicators: Added progress bars to each sorting feature to clearly show current step and overall progress.
  • Navigation Improvements: Updated BST navigation links to lead directly to the dedicated BST landing page instead of the homepage.
  • Instructional Content: Incorporated an instructional section explaining merge and insertion sort algorithms with visual cues and step-by-step guidance.
